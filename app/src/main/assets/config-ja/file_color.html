ファイル選択画面-色設定

ファイル選択画面の色設定

ファイル選択画面で使用する色を設定します。

プリセット色

プリセット色の選択

アプリで用意している配色のプリセットを選択します。
「カスタム」「標準（黒）」「標準（白）」「桜」「藍」「葉」「橙」「墨」から選べます。
好きな色を指定したい場合は「カスタム」を選択してください。

プリセットの反映

現在選択中のプリセットの配色をカスタム設定の各項目に反映します。

カスタム設定

プリセットの選択で「カスタム」を選択したときに有効になります。
画面を構成する個々の部品について、以下の設定項目で任意の色を設定できます。

サーバー選択のテキスト色

サーバー選択画面のサーバー名のテキスト色です。

ディレクトリの色

ファイル選択画面のディレクトリのテキスト色です。

未読ファイルの色

ファイル選択画面の未読の圧縮ファイルのテキスト色です。

読みかけファイルの色

ファイル選択画面の読みかけの圧縮ファイルのテキスト色です。

既読ファイルの色

ファイル選択画面の既読の圧縮ファイルのテキスト色です。

読書率の背景色

読書率のドーナツチャート又は進捗バーの背景色です。

イメージファイルの色

ファイル選択画面のイメージファイルのテキスト色です。

ファイル情報の色

ファイル選択画面のファイル更新日付やファイルサイズのテキスト色です。サーバー選択画面のURIのテキスト色にも使われます。

マーカーの色

マーカーで強調表示する項目の色です。

リストの背景色

ファイル選択画面のリストの背景色です。

選択時の色

リストの項目を選択したときの色です。

タイトルのテキスト色

ファイル選択画面上部のファイルパスを描画しているエリアのテキスト色です。

タイトルの背景色

ファイル選択画面上部のファイルパスを描画しているエリアの背景色です。

ツールバーの描画色

ツールバーのアイコンや文字の描画色です。

ツールバーのボタン色

ファイル選択画面のツールバーのボタンの色です。

本棚のテキスト色

本棚表示でのファイル名のテキスト色です。

本棚のテキストの縁取りの色

本棚表示でのファイル名の縁取りの色です。

フローティングアイコンの色

フローティングアイコンの描画色です。

フローティングアイコンの背景色

フローティングアイコンの背景色です。

WebベースのEPUBファイルの文字色

WebベースのEPUBビューアで表示する文字の色です。

WebベースのEPUBファイルの背景色

WebベースのEPUBビューアの背景色です。

タブのテキストの色

タブ表示のタブに描画するテキストの色です。
