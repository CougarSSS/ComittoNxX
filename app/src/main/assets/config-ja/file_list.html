ファイル選択画面-設定

ファイル選択画面設定

ファイル選択画面の表示と操作に関連する設定です。

起動と基本動作

起動時のサーバー選択

起動時に最初に表示するサーバーを設定します。
「なし」、「ローカル」、「サーバー設定1〜10」から選択します。

前回のファイルをオープン

起動時に前回表示したファイルを自動的に開きます。

前回表示したファイルを自動で開く

前回のファイルを開く際の確認ダイアログを表示しません。

表示方向

ファイル選択画面を表示する向きを設定します。
カメラボタンによる回転は縦固定又は横固定の場合のみ動作します。
  • 回転あり
    • 本体の向きに合わせて自動的に画面を回転します。
  • 縦固定
    • 本体の向きに関係なく画面を縦向き表示に固定します。
  • 横固定
    • 本体の向きに関係なく画面を横向き表示に固定します。
  • 回転あり(縦上下反転)／回転あり(横上下反転)／回転あり(縦横上下反転)
    • 上下反転を許可して自動的に画面を回転します。
  • 縦固定(上下反転)／横固定(上下反転)
    • 上下を反転した状態で縦向き又は横向きに固定します。

Backキーの動作

ファイル選択画面でBackキーを押したときの動作を設定します。
  • ComittoNxXの終了
    • Backキーの二度押しでアプリを終了します。
  • 親ディレクトリに移動
    • ファイルリストの親ディレクトリに移動します。
    リスト中の「..」やツールバーの「上へ」を選択と同じです。
  • 前のディレクトリに戻る
    • ディレクトリを移動した履歴を逆に戻っていきます。

ダイアログの戻るキーによるキャンセル

ファイルリストの読み込みダイアログの表示を、戻るキーでキャンセルできるようにします。

ショートカットで既存タスク終了

ショートカットから起動したときに既存のタスクを終了します。
設定後に新しく作成するショートカットから有効になります。

ソート

ソート表示

ファイルリストの表示順番を設定します。
  • ソートなし
    • ファイル一覧を取得したそのままの順番で表示します。
  • ファイル名(ディレクトリ混在)／(ディレクトリ分離)
    • ファイル名の順で表示します。「混在」ではディレクトリとファイルを区別せず、「分離」ではディレクトリを先に示します。
  • 新しい順／古い順(ディレクトリ混在／分離)
    • 更新日付の新しい順又は古い順で表示します。
  • シャッフル(ディレクトリ混在／分離)
    • ランダムな順番で表示します。

ソート表示のファイル別設定

ファイルの種類ごとに並び順を個別に設定する画面を開きます。
詳細は後述の「ソート表示のファイル別設定」を参照してください。

ソートのシャッフル内容を保持

シャッフルした並び順を、リストの更新又はソートのモードが変更されるまで保持します。

ファイルのソート処理を省略

ソート済みのファイルリストを用いてアクセス時間を短縮します。
ソートに失敗する場合はチェックを外してください。

リスト表示

親ディレクトリ表示

ファイルリストに親ディレクトリへの移動項目(上矢印)を表示します。

拡張子の表示

ファイル名の拡張子を表示します。

リスト表示の拡張子を表示しない

リスト表示のときだけファイル名の拡張子を表示しません。

ファイル名の分割

タイル表示でファイル名を[]()で分割して表示します。

タイル表示のテキストの行数

タイル表示でファイル名を表示する最大行数(1〜10)を設定します。

削除メニューの表示

ファイルの長押しメニューに「ファイル削除」を表示するかを設定します。
「表示しない」「表示する」「ローカルのみ表示」「サーバーのみ表示」から選択します。

名前変更メニューの表示

ファイルの長押しメニューに「名称変更」を表示するかを設定します。
選択肢は削除メニューの表示と同じです。

リスト表示に戻る際に元の位置を保持する

ビューアから戻ったときにリストをスクロールさせず元の位置のまま表示します。再起動後に有効になります。

タップでファイル展開表示

zip/rar/pdfをタップしたとき、ファイルの内容を展開して一覧表示します。

EPUBファイルをイメージ表示画面で開く

EPUBファイルをテキスト表示画面の代わりにイメージ表示画面で開きます。

ファイルの展開でテキストを有効にする

ファイルの展開表示でテキストファイルも選択できるようにします。
イメージビューアでテキストのページを選択するとエラーになるため、自己責任で使用してください。

フォントと余白

タイトルのフォントサイズ

画面上部のタイトル(ファイルパス)を描画するフォントサイズを設定します。

ファイル名等のフォントサイズ

ファイル名を描画するフォントサイズを設定します。

サマリのフォントサイズ

ファイル更新日付とファイルサイズを描画するフォントサイズを設定します。

タイル用フォントサイズ

タイル表示でファイル名を描画するフォントサイズを設定します。

項目の余白サイズ

リストの各項目の余白の大きさを設定します。

ツールバー

ツールバーのアイコン名

ツールバーのアイコンの下にボタン名を表示します。

ツールバーのサイズ

ツールバーの大きさを設定します。

長押し系操作の時間

長押しとして扱う時間を設定します。

サムネイル

サムネイルのサイズ

サムネイルの描画サイズを設定します。スライダーで段階的に指定します。
列数で指定する設定が有効な場合は、列数からサイズが決まります。

リスト表示のサムネイルサイズ

リスト表示でのサムネイルの大きさを設定します。

サムネイルグリッドを列数で指定

サムネイルのタイル表示を、サイズではなく列数で指定します。
列数を増やすとサムネイルの表示更新に失敗する場合は、サムネイルのサイズを小さくしてください。

サムネイルグリッドの列数(縦)／(横)

列数で指定する場合の、縦向き(1〜8列)及び横向き(1〜16列)での列数を設定します。

タイル表示のサムネイルの拡大率／リスト表示のサムネイルの拡大率

サムネイルを表示する際の拡大率をそれぞれ設定します。

サムネイルのキャッシュ

サムネイルのキャッシュを保持するファイル数を設定します。
「保持しない」「最大100ファイル」「最大500ファイル」「最大1000ファイル」「削除しない(手動削除)」から選択します。

先頭ファイル名のサムネイル作成

圧縮ファイル中の全ファイル名を解析して先頭のファイルを求め、サムネイルにします。RARファイルはかなり遅くなります。

先頭ファイル名のサムネイル作成条件(サーバ種別)

上記を行う対象を「なし」「ローカル」「ローカルとSMB」「すべて」から選択します。

サムネイルの切り取り位置

サムネイルとして切り出す位置を「中央」「左」「右」「全体を表示」「紙の表紙カバーに合わせる」から選択します。

サムネイルの余白削除

画像の余白を取り除く強さを「なし」「弱」「中」「強」「特上」「最強」から選択します。

サムネイルONで長押しメニューを有効

サムネイル表示のとき、リスト表示ではサムネイル、タイル表示ではファイル名をタップして長押しメニューを表示できるようにします。

サムネイル取得の失敗時に次からスキップさせる

サムネイル取得でエラーが起きて時間が掛かる場合に、次回からその取得を省略します。
再度取得したいときは、ファイルの長押しメニューから「サムネイルキャッシュ削除」を選択してください。

読書率の表示

読書率のドーナツチャートを表示しない

ファイルごとの読書率を示すドーナツチャートを表示しません。

リスト表示の読書率のテキスト表示

読書率のテキストの表示方法を「通常表示」「表示しない」「日付サイズの後へ表示」から選択します。

読書率のドーナツチャート/進捗バーの選択

読書率を示す形式を「ドーナツチャート」又は「進捗バー」から選択します。

読書率の進捗バーの座標

進捗バーを表示する位置を「ドーナツチャートと同じ座標」「上側」「下側」から選択します。

読書率の進捗バーの横幅設定

進捗バーの横幅を「サムネイル画像に合わせる」又は「サムネイル表示エリアに合わせる」から選択します。

プログレスバーの右端の表示を実際の値にする

プログレスバーの右端に、割合ではなく参照している実際の値を表示します。

リスト表示に戻る際の時間短縮を使用しない

更新ボタンを押さないと既読状態が反映されない場合にチェックを入れます。

マーカー設定

マーカー設定ダイアログの各チェックの初期状態を設定します。
  • マーカー設定のフィルタのチェック
  • マーカー設定のディレクトリのチェック
  • マーカー設定のファイルのみのチェック
  • マーカー設定のフォルダのみのチェック
それぞれ、チェックを入れるとダイアログを開いたときに該当項目が最初からオンになります。

ファイルの読み込み

ファイルリストのキャッシュファイルを参照しない

ファイルリストのキャッシュが破損しているなどしてアクセスに失敗する場合にチェックを入れます。

圧縮ファイルの識別でマジックナンバーを参照する

圧縮ファイルの識別を自動判定からマジックナンバーによる固定の判定に変更し、識別の時間を短縮します。

ZIPファイルの読み込みを旧方式で行う

ZIPの展開ライブラリを使用しません。ファイル先頭の画像やサムネイルが読み込めない場合に有効なことがあります。
64bit/LZMA/Bzip2形式のZIPファイルが開けなくなります。

RARファイルの読み込みを旧方式で行う

RARの展開ライブラリを使用します。ファイル先頭の画像やサムネイルが読み込めない場合に有効なことがあります。

青空文庫のZIPファイルの読み込みを行う

青空文庫のテキストを含んだZIPファイルを識別します。WebベースのEPUBビューアで表示します。

青空文庫のテキストファイルの読み込みを行う

青空文庫のテキストファイルを識別します。WebベースのEPUBビューアで表示します。

pdfファイルを開く前に一時ファイルへ展開

ローカル以外のpdfファイルを開く前に一時ファイルへ展開して、ページ送りを速くします。

ファイル一覧画面の更新をスキップ

履歴やブックマークからビューアを開くときに、ファイル一覧画面の更新を省略します。
現在のファイル一覧と異なる場合は更新が行われます。

HTML／テキストのリンク先の画像

HTMLのリンク先の画像をイメージビューアで開く／テキストのリンク先の画像をイメージビューアで開く

リンク先の画像を、イメージビューアで開きます。

リンク先の画像の取得をバックグラウンドで行う

リンク先の画像を一括でダウンロードせず、ページの先読み時にバックグラウンドで取得します。

HTMLとテキストのリンク先の画像の取得ページ数を制限する

ページの先読み時に取得するページ数を制限します。

HTMLとテキストのリンク先の画像の取得ページ数の制限サイズ

制限する場合のページ数を設定します。

既読位置・しおりの引き継ぎ

既読位置を引くべきキーを解決する

既読位置・既読/未読状態を探すとき、まず完全に一致する記録を探し、見つからなければ同じサーバー内でファイル名(圧縮ファイルの拡張子は無視)が一致する直近の記録を使用します。
ZIPとRARの拡張子違いや、ディレクトリを移動した後でも既読位置を引き継げます。見つからない場合は通常どおり未読として扱います。

ブックマークの元ファイルに紐づく全レコードを集めて返す

完全に一致する栞・履歴が無かった場合に、同じサーバー内でファイル名(圧縮ファイルの拡張子は無視)が一致する直近の記録一式(複数件の栞など)を使用します。
ZIPとRARの拡張子違いやディレクトリ移動後でも、栞・履歴を引き継げます。

タブ表示

ファイル選択画面のタブ表示を有効にする

ファイル選択画面をWebブラウザのようにタブで切り替えて使えるようにします。

タブ表示のスタイル選択

「Webブラウザスタイル」又は「＋×ボタン配置スタイル」から選択します。

タブのサイズ

タブの大きさを設定します。

タブの上下配置の切り替え

タブを「画面上側」又は「画面下側」に表示します。

タブの状態を復元

再起動時にタブの状態を復元します。

ソート表示のファイル別設定

「ソート表示のファイル別設定」を開くと、次の設定ができます。

ソート表示のパラメータ設定

  • ディレクトリを先頭に集める
    • ディレクトリを先頭に表示します。
  • 最優先で先頭に表示するファイルの種類
    • 「指定なし」「ディレクトリ」「圧縮ファイル」「画像ファイル」「PDFファイル」「EPUBファイル」「テキストファイル」「その他のファイル」から、他の種類より先に表示する種類を選択します。

ソート表示のファイル別設定

ディレクトリ・圧縮ファイル・画像ファイル・PDFファイル・EPUBファイル・テキストファイル・その他のファイルそれぞれについて、並び順を設定します。
  • ソート表示の設定に従う
  • ファイル名(昇順)／ファイル名(降順)
  • 新しい順／古い順
  • シャッフル
  • 読書中の割合が多い順／読書中の割合が少ない順
