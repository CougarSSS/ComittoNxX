共通-設定

共通の設定

ファイル選択画面とイメージ表示画面などで共通の設定です。

共通設定

リリースを確認する

定期的に新しいバージョンがリリースされていないかを確認します。

.で始まるファイルを表示しない

一部のOSで隠しファイルとして扱う”.”で始まるファイルを非表示にする設定です。
Mac OS Xで作成したZIPファイルの中に画像を格納した場合に作成される、”.”で始まり拡張子がjpg又はpngで画像ではないファイルを非表示にできます。

画面を回転するボタン

ファイル選択画面とイメージ表示画面で画面の向きを回転するためのボタンを設定します。
端末によりフォーカスボタンの有無やシャッターボタンが押しにくいなどがありますので、操作しやすいボタンを設定してください。
  • 使用しない
  • カメラフォーカスボタン
  • カメラシャッターボタン

すべての画面でナビゲーションバーを表示しない

強制的にナビゲーションバーを非表示にします。設定の反映にはアプリの再起動が必要です。

すべての画面でステータスバーを表示しない

強制的にステータスバーを非表示にします。設定の反映にはアプリの再起動が必要です。

表示方向の設定で新方式を使う

逆方向（上下反転）の回転に対応させる場合にチェックを入れます。再起動で反映されます。

表示方向の切り替え時に向きを逆にする

ハードウェアキーで表示方向を切り替える時に上下を逆さにする場合にチェックを入れます。再起動で反映されます。

ビューアからの設定呼び出しで元の画面に固定

ビューアから設定を呼び出した時に、表示方向を呼び出し元の画面の向きに固定する場合にチェックを入れます。再起動で反映されます。

表示方向(ビューア以外全て)

ビューア以外のすべての画面を表示する向きを設定します。
  • 回転あり
  • 縦固定
  • 横固定
  • 回転あり(縦上下反転)
  • 回転あり(横上下反転)
  • 回転あり(縦横上下反転)
  • 縦固定(上下反転)
  • 横固定(上下反転)

起動時のテーマ選択

アプリ全体の明暗テーマを選択します。再起動で反映されます。
  • ライトモード
  • ダークモード
  • システム設定に従う

文字コード

自動判別

文字コードを自動判別します。判別できない場合は指定した文字コードを使用します。

文字コード指定

ZIP又はRARファイル内のファイル名などをどの文字コードとして扱うかを設定します。
Windowsで作成したZIPファイルはShift_JIS、Mac OS Xで作成したZIPファイルはUTF-8になっているようです。
  • UTF-8
  • Shift_JIS
  • EUC-JP
  • EUC-KR
  • Big5
  • GB2312
  • GB18030
  • Big5-HKSCS

ソートの設定

ファイル名で並べ替える時の比較方法を設定します。

全角半角を区別しない

全角を半角に変換してから比較します。

大文字小文字を区別しない

半角小文字 [a-z] を半角大文字 [A-Z] に変換してから比較します。

記号の順番を変える

記号をWindowsのエクスプローラーに似せた順番で並べます。

自然数順で並べる

0001のように桁数を合わせていない数字も大小順に並べます。小数や3桁毎のカンマ区切りにも対応します。

漢数字で並べ替える

「〇一二三四五六七八九十百千万億兆」や「零壱弐参肆伍陸漆捌玖拾什廿卅丗佰仟阡萬」の順に並べます。

上中下巻で並べ替える

「上中下」や「前中後」の順に並べます。「完短外」はその次に並びます。

ファイルを優先する

ディレクトリよりファイルを優先します。イメージビューアとサムネイルのみ有効です。

ソートの優先ワード

ファイル名に含まれていると、ソート順序が最小の文字として扱われる優先ワードを設定します。

優先ワード1～10

最大10個まで登録できます。初期値は優先ワード1が「cover」で、それ以外は空欄です。

テーマの切り替え

テーマのプリセット値（ファイル選択画面のフォントサイズ・余白・ツールバーサイズ、およびファイル選択画面の配色）をまとめて切り替える設定です。

テーマの切り替えを有効にする

チェックを入れると、テーマの切り替えが有効になります。

プリセット値

システム設定、テーマ1～テーマ8から選択します。それぞれのテーマに設定値が個別に保存されます。

ファイル選択画面設定

タイトル、ファイル名等、サマリ、タイル表示のフォントサイズ、項目の余白サイズ、ツールバーのサイズをテーマごとに設定します。

プリセット色

カスタム、標準（黒）、標準（白）、桜、藍、葉、橙、墨から配色を選択します。「プリセットの反映」を選ぶと、選択中のプリセットの配色がカスタム設定の各項目に反映されます。

カスタム設定

次の各色を個別に設定します。
  • サーバー選択のテキスト色 / ディレクトリの色
  • 未読ファイルの色 / 読みかけファイルの色 / 既読ファイルの色
  • 読書率の背景色 / イメージファイルの色 / ファイル情報の色
  • マーカーの色 / リストの背景色 / 選択時の色
  • タイトルのテキスト色 / タイトルの背景色
  • ツールバーの描画色 / ツールバーのボタン色
  • 本棚のテキスト色 / 本棚のテキストの縁取りの色
  • フローティングアイコンの色 / フローティングアイコンの背景色
  • WebベースのEPUBファイルの文字色 / 背景色
  • タブのテキストの色

Webview画面の設定

HTMLファイルを表示するWebview画面の設定です。

Webview画面でフィルターを有効にする

HTMLファイル内の画像にフィルターを適用します。

フィルターのプルダウンメニューを有効にする

画面上端をタップすると、フィルターのプルダウンメニューを表示します。

画面上端のタップ位置

プルダウンメニューを表示するタップ位置（中央上／左上／右上）を設定します。

デスクトップ用のUser-Agentにする

User-AgentをPC版に偽装します。

フィルターの設定

次の項目を設定できます。
  • グレースケール化 / 色反転 / 自動着色
  • 画像シャープ化 / 明るさ補正 / ガンマ補正 / コントラスト
  • 色相 / 彩度 / 色温度
  • RGBレベルをマニュアル設定（赤レベル／緑レベル／青レベル）

Web共有の設定

端末内のファイルをWebブラウザから参照・ダウンロードできるようにする機能の設定です。

現在のステータス

Web共有の動作状態を表示します。

Web共有の開始/停止

Web共有の開始及び停止を行います。

起動時にWeb共有を有効にする

アプリの起動時にWeb共有を開始します。

Web共有の開始・停止のアイコンを表示

Web共有の開始・停止を行うアイコンを表示します。

ポート番号

Web共有で待ち受けるポート番号です。初期値は8080です。

Web共有の初期フォルダの選択

Web共有で最初に表示するフォルダを選択します。

「選択をZIP圧縮してダウンロード」する時のファイル名

複数選択したファイルをZIP圧縮してダウンロードする時のファイル名です。初期値は「archive」です。

ファイルをクリックまたはタップした時にポップアップ表示する

ファイルの内容を確認したい場合にチェックを入れます。

認証モード

Web共有へのアクセス時の認証方式を、無し／Basic認証／Digest認証から選択します。

ユーザー名／パスワード

認証用のユーザー名とパスワードを設定します。

自己署名証明書によるTLS(HTTPS)を有効

自己署名証明書を動的に作成して、TLS(HTTPS)で通信します。

読み取り専用モードを有効

チェックを入れると、Web共有からの変更操作ができなくなります。

カスタムURLスキームの設定

認証キー

外部アプリなどからカスタムURLスキームでファイルを開く際に照合する認証キーを設定します。初期値はアプリケーションIDです。

SMB(Server Message Block)の設定

Windowsファイル共有(SMB)へのアクセスに関する設定です。

ComittoN 互換モード

ComittoN 互換モード(SMB1のみ)でアクセスします。

圧縮ファイルの展開ライブラリの再試行を緩和

圧縮ファイルの展開ライブラリのアクセス失敗による再試行の待ち時間を長くして、再試行の頻度を減らします。

SMBのコールバックの手直しを行わない

SMBのコールバックのサイズ取得と読み出し部分の手直しを行いません。2.4.10.BV以前の動作になります。
