サーバ選択画面-設定

サーバ選択画面の説明

サーバの登録

リスト中の設定したい位置の項目を長押しすると設定画面が表示されますので、サーバの情報を入力してください。
設定済みのリスト項目であれば設定されている内容が表示されます。
「クリア」で入力内容を消去、「OK」で登録、「キャンセル」で変更を破棄します。
  • アクセスタイプ
    • 接続方法を選択します。
    「SMB」(Windows共有など)、「ストレージ アクセス フレームワーク」(端末内外のストレージやクラウド)、「ファイル ピッカー」、「WebDAV」から選択できます。
    選択した種類によって、以下の入力項目が変わります。
  • 表示名
    • リストへの表示にのみ使用する名称です。
    この項目を設定していない場合はリストに「未定義」と表示されますので、人に見せたくないサーバであれば使用するときだけ表示名を設定するという使い方もできます。
  • ホスト情報（SMB／WebDAV）
    • 接続先サーバの情報を「サーバ名/共有フォルダ」の形式で入力してください。
    サーバ名のみの指定や、深い階層のパスでも指定可能です。
    ここで指定されたパスがルートディレクトリとなり、上のパスには移動できません。
    例）192.168.1.120/comics/雑誌
  • アカウント名（SMB／WebDAV）
    • サーバ接続時の認証に使用するアカウント名を入力してください。
    匿名接続の場合は空欄に、ゲストの場合は guest と入力します。
    ドメインがある場合は「Domain;User」の形式で入力します。
  • パスワード（SMB／WebDAV）
    • サーバ接続時の認証に使用するパスワードを入力してください。
    認証が不要な場合は空欄にしてください。
  • URL（ストレージ アクセス フレームワーク）
    • 「選択してください」を押して接続先のフォルダ又はサービスを選択します。選択後は「選択済」と表示されます。

サーバへの接続

リストから接続したいサーバ情報を選択すると接続されます。

起動時に接続するサーバ

「ファイル選択画面-設定」の「起動時のサーバー選択」で、起動時に最初に開くサーバーを指定できます。
