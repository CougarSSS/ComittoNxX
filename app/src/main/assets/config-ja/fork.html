独自拡張機能(full-local-features)

このページは、本家(comittonxxa2/ComittoNxX)のヘルプに含まれない、このフォーク独自の機能の説明です。
本家の機能の説明は他のページを参照してください。
※本家に同名の設定画面がある機能も含みます(同期・Everything検索など)。ここでは使い方をまとめて説明します。

1. 同期サーバーによる栞・既読位置・履歴・書庫カタログの共有

別途自己ホストするREST APIサーバー(bookmark-sync-server)を使って、複数端末間で次の情報を共有します。
対象はSMB共有上のファイルのみです。ローカルのファイルは対象外です。
  • 栞(ブックマーク)の追加/削除
  • 既読位置(最後に開いたページ位置)
  • 履歴(最近開いたファイル)
  • 書庫カタログ(SMB共有上のアーカイブ一覧)
サーバーのAPI仕様はリポジトリの docs/bookmark-sync-api.md にあります。仕様を満たせば自作のサーバーでも利用できます。

設定の場所

設定の「栞(ブックマーク)同期の設定」で行います。
  • 栞(ブックマーク)同期を有効にする
  • 既読位置の同期を有効にする
  • 履歴の同期を有効にする
  • 書庫管理のタブを有効にする
  • ホストIPアドレス / ポート番号 / ユーザー名 / パスワード：サーバーの接続先です。
  • サーバーのソースコードをダウンロード

既読位置の同期の動作

  • SMB上の圧縮ファイル(ZIP/RAR等)を開く直前にサーバーへ問い合わせ、サーバー側に記録があればローカルより優先して復元してから開きます。
  • ページ送りのたびではなく、ビューアを閉じるとき、他の画面へ切り替えるとき、バックグラウンドへ移るときにサーバーへ反映します。
  • サーバーに接続できない場合でも、ファイルを開く動作や読書自体は継続できます(同期は最大でも数秒の待ち時間で打ち切られます)。
  • EPUBと青空文庫は総ページ数が端末ごとに異なるため、ページ番号ではなく進捗の割合で同期します。
  • 設定のエクスポート/インポートには、SMB上のファイルの既読位置は含まれません(サーバー側で管理されるため)。

既読位置を手動で同期する

ファイル一覧のツールバーの同期ボタン、または書庫管理タブのメニュー「既読位置を更新」で、そのサーバーの既読位置をまとめて取得します。
同期設定が未設定の場合や、ローカルのファイル一覧では利用できません。

2. Everything検索

Everything(Windows)またはEverythingXでファイルを検索し、結果から直接ファイルやフォルダを開く機能です。
ファイル一覧の下部に「検索」タブが追加されます。
検索結果のパスは、設定の置換ルールでSMBのパスに変換して、登録済みのSMBサーバーのホストと照合して開きます。
該当するホストのSMBサーバーが登録されていない場合は、先にサーバー一覧へ追加してください。

設定の場所

設定の「Everything検索の設定」で行います。
  • Everything検索を有効にする
  • IPアドレス / ポート番号 / ユーザー名 / パスワード：検索サーバーの接続先です。
  • 置換対象元 / 置換対象先：検索結果のパスの一部を置き換えて、SMBのパスに合わせます。

3. 書庫管理タブ

同期サーバー上の書庫カタログを、作品(タイトル)単位でまとめて閲覧するタブです。
設定の「書庫管理のタブを有効にする」をオンにすると、ファイル一覧の下部に追加されます。
作品名は、サーバー側でフォルダ構成などから算出した作品名を使ってまとめています。
フォルダ(サブフォルダを含む)が分かれている場合は別の作品として扱われます。

作品一覧

  • 先頭の行をタップするとタイトルの一部で絞り込み検索ができます。
  • 各作品には巻数と、既読の集計「既読: 読了した巻数/全巻数 (割合)」が表示されます。
  • 題名の色は、全巻既読・全巻未読・読書中(一部既読)で色分けされます。色は「ファイル選択画面の色設定」と共通です。
  • 集計は一覧の表示を止めないよう裏で計算するため、表示から少し遅れて反映されることがあります。
  • 作品をタップすると、その作品の巻一覧(ドリルダウン)に移ります。

巻一覧

  • 巻ごとに、更新日時・サイズ・所属フォルダ名・既読状況(未読／NN% Read／100% Read)が表示され、題名が既読状況で色分けされます。
  • 同じ作品でも、漫画フォルダとAria2c_DLフォルダなど別のフォルダにある巻が並ぶことがあります。
  • 巻をタップするとその巻を開きます。先頭の「« 作品名」の行をタップすると作品一覧へ戻ります。
  • ビューアでの「次のファイル/前のファイル」は、その作品の巻の範囲で移動します。別のフォルダの巻へも続けて移動できます。作品の最後の巻まで来ると、他の作品へは進まずに終了します。

書庫管理タブのメニュー

  • サーバー側を更新：サーバーにSMB共有のスキャンを開始させます。完了までに数十秒〜数分かかります。直近でスキャン済みの場合は実行されません(連続実行の制限があります)。
  • 端末側を更新：サーバー上の現在のカタログを端末に取得します。サーバー側の更新が終わってから実行してください。
  • 既読位置を更新：サーバー上の既読位置を取得して、既読状況の表示に反映します。
  • タイトルで検索 / 絞り込みを解除：作品名の絞り込みを行う／解除します。

長押しメニュー

  • 作品を長押し：存在確認して実在しない巻を削除。サーバー上に実際にあるかを確認し、無い巻をカタログの端末側の控えから消します。サーバーに接続できないときは何も削除しません。
  • 巻を長押し：上記に加えて次が選べます。
    • 未読にする：その巻の既読位置を消して未読に戻します。
    • 既読にする：その巻を既読にします。
    • 先頭ページを開く：既読位置を無視して先頭ページから開きます(既読位置は消しません)。
SMBサーバー上の巻は、未読／既読にした結果をサーバーにも反映します(反映しないと、開くときにサーバー側の古い既読位置が優先されて元に戻ってしまうため)。

4. 拡張子違い・ディレクトリ移動後の既読/栞の引き継ぎ

ZIPとRARなど拡張子が変わったファイル、または別のディレクトリへ移動したファイルでも、既読位置・既読/未読状態・栞・履歴を引き継ぐ機能です。
まず完全一致で探し、見つからなければ、同じサーバー内でファイル名(アーカイブの拡張子は無視)が一致する直近のレコードを使います。
イメージビューア(圧縮ファイル)とファイル一覧、書庫管理タブが対象です。テキスト/EPUBビューアは、内部のパスと連結したキーを使うため対象外です。
設定の「ファイル選択画面の設定」にある次の項目で切り替えます(どちらも初期値は有効)。
  • 既読位置を引くべきキーを解決する
  • ブックマークの元ファイルに紐づく全レコードを集めて返す

5. その他の独自の変更

  • マーカー設定：ディレクトリのチェックに加えて、「ファイルのみ表示」「フォルダのみ表示」の切り替えを追加しました。
  • ファイル一覧の表示の高速化：既読位置の検索を事前に索引化し、ファイル数の多いフォルダでの表示を速くしました。
  • SMBファイルハンドルの解放：7-Zip-JBindingでアーカイブを開いたとき、SMB側のファイルハンドルが残る不具合を修正しました。
  • SMB接続設定の反映：バックグラウンド経路が先に初期化するとチューニング設定が反映されないことがある不具合を修正しました。
  • 遅延の記録：開くのが遅いアーカイブや同期の待ちが長いときは、ログ(Logcat)に常に記録します。
